*sqlite3.c, sqlite3.h, bancadb*
->Il modo più semplice per integrare SQL in questa struttura senza installare programmi esterni è andare sul sito ufficiale di SQLite (nella sezione Download) 
e scaricare l'Amalgamation (un file ZIP).
-->Estrai i file sqlite3.c e sqlite3.h e inseriscili nella cartella principale del tuo progetto.
-->database_manager.h e .cpp ti serviranno per non "sporcare" il main.cpp: lì dentro scriverai le funzioni per salvare i conti correnti e per cercare i lavori nella cache.
-->Il file banca.db non devi crearlo tu. Apparirà in quella cartella non appena il tuo codice C++ proverà a connettersi per la prima volta.

*/imgui*
->Scarica la libreria Dear ImGui da GitHub. È una libreria di file sorgente (non ha bisogno di installazioni complesse).
-->Crea una cartella chiamata imgui nella tua directory.
-->Copia al suo interno i file principali che trovi nella repository di ImGui (quelli elencati nell'albero sopra).
-->Per far funzionare la grafica su schermo, ImGui ha bisogno di un "backend" per creare la finestra (di solito si usano librerie leggerissime come GLFW o SDL2 accoppiate a OpenGL).
I file d'esempio imgui_impl_xxxx.cpp servono proprio a questo.
