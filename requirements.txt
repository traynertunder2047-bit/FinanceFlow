Dato che stai aggiungendo nuovi file .cpp (sqlite3.c, database_manager.cpp e i file di ImGui),
devi dire al compilatore C++ di includerli nel processo di compilazione, altrimenti riceverai errori di tipo "Undefined reference".

Dovrai modificare il tuo file tasks.json dentro la cartella .vscode. Nella sezione "args", dove viene invocato il compilatore (es. g++),
assicurati che invece di compilare solo main.cpp o i file singoli, compili tutti i file della cartella e di ImGui.

Il consiglio migliore resta quello di procedere per gradi: prima crea scraper.py e i file del database per far funzionare tutta la logica da terminale e,
solo quando tutto salva e legge alla perfezione nel file .db, dedicati a inserire i file della cartella imgui per disegnare la tua interfaccia bancaria.


esempio configurazione per compilatore su tasks.json:
"args": [
    "-g",
    "${workspaceFolder}/*.cpp",          // Compila tutti i tuoi file .cpp principali
    "${workspaceFolder}/sqlite3.c",       // Compila il motore del database
    "${workspaceFolder}/imgui/*.cpp",     // Compila la libreria grafica
    "-o",
    "${workspaceFolder}/output/AccountBankManager.exe",
    // Se usi GLFW per la finestra grafica, dovrai aggiungere anche i suoi link:
    "-lglfw3", 
    "-lopengl32"
]
